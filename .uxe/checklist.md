# UXE Checklist

- [ ] Product mode declared: `document-editor`
- [ ] `.uxe/contract.json` read before UI/CSS edits
- [ ] Target surface declared before edits
- [ ] Typography changes mapped to `.uxe/token-map.json`
- [ ] Color/radius/spacing selector bindings and aliases bridge to mapped tokens
- [ ] Rendered surface parity checked for every affected parity group
- [ ] `uxe:check` or fallback drift checks run
- [ ] `uxe:component` or fallback component semantics checks run
- [ ] `uxe:taste` or fallback page taste checks run
- [ ] `uxe:contract` or fallback style token consumption checks run
- [ ] `uxe:capture` or equivalent screenshot/computed-style capture run
- [ ] `uxe:visual` or screenshot/computed-style evidence captured
- [ ] `uxe:audit` or aggregate UXE audit run
- [ ] Final response reports contract, surfaces, tokens, checks, deviations
